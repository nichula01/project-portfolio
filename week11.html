Week 11 - Project Progress

This week focused on expanding the dataset from tri-temporal flood imagery to bi-temporal tsunami and wildfire image pairs with binary change masks, while also studying change detection papers to improve dataset structure and benchmark quality.

At a glance

Dataset expansion and sample preparation

Core progress from hazard-type expansion, image-pair curation, mask preparation, and paper-based learning.

What I completed

  • Expanded the dataset scope from tri-temporal flood images to bi-temporal tsunami and wildfire images.
  • Organized image pairs into a standard Before and After format.
  • Prepared corresponding binary change masks for supervised change detection use.
  • Collected and arranged a sample wildfire image set from California 2021.
  • Reviewed related change detection papers to improve dataset structure, documentation, and benchmark design.

Dataset direction

The project moved from a flood-focused tri-temporal setup toward a broader hazard dataset with bi-temporal image pairs for tsunami and wildfire events. This makes the dataset more flexible for standard change detection pipelines that use paired images and a binary mask.

Paper study

Learning points from related change detection papers

Reading notes were translated into practical improvements for dataset design, organization, and future benchmarking.

Key learning points

  • Use a clear and consistent triplet structure: before image, after image, and binary change mask.
  • Keep preprocessing and naming conventions standardized so the dataset is easy to use in training and evaluation pipelines.
  • Document how masks are created and define change classes carefully to improve reproducibility.
  • Include strong baseline-ready splits and evaluation protocols from the beginning.
  • Show representative visual examples because they help explain the difficulty and value of the dataset.
  • State the event type, acquisition conditions, and possible challenges such as smoke, cloud, seasonal differences, or illumination changes.

How the papers helped this week

Paper Why it was useful Practice adopted
whucd.pdf Helped understand how a benchmark-style change detection dataset should be organized and presented. Adopted the paired-image plus mask structure and emphasized visual sample quality.
