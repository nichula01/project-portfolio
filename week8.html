Week 8 - MSI Change Detection (Tri-temporal)

This week I built a compact Colab workflow to validate Sentinel-2 MSI triplets and generate tri-temporal change masks using spectral indices.

Data: Sentinel-2 MSI triplets (BEFORE / ON / AFTER) Core idea: Index differencing + persistent vs transient change Outputs: NDVI/NDWI rasters + change masks (GeoTIFF + PNG)

At a glance

Tri-temporal MSI workflow

Main progress, methods, and outputs from Week 8.

Objectives

  • Build a repeatable notebook for MSI triplet validation.
  • Generate tri-temporal change masks with NDVI/NDWI deltas.
  • Export clean outputs for dataset and model testing.

Work Done

  • Validated triplet completeness and Sentinel-2 band mapping.
  • Created RGB/false-color views and band inspection grids.
  • Computed NDVI/NDWI and delta maps against BEFORE.
  • Applied Otsu thresholding and morphological cleanup.
  • Exported GeoTIFF and PNG outputs per triplet.

Tools / Methods Used

  • Google Colab for notebook workflow.
  • MSI GeoTIFF read/write and quick visualization.
  • NDVI, NDWI, and delta-index comparison.
  • Otsu thresholding + morphology for mask cleanup.

Key Technical Details

Index definitions

  • NDVI = (NIR - Red) / (NIR + Red)
  • NDWI = (Green - NIR) / (Green + NIR)
// Reduced tri-temporal mask logic
d_on = idx_on - idx_before
d_after = idx_after - idx_before

mask_on = Otsu(abs(d_on))
mask_after = Otsu(abs(d_after))

mask_on = clean(mask_on)
mask_after = clean(mask_after)

persistent = mask_on AND mask_after
transient = mask_on AND (NOT mask_after)

Results / Observations

  • False-color composites made vegetation/moisture shifts clearer than RGB.
  • Otsu gave a strong adaptive baseline for different scenes.
  • Persistent vs transient split helps interpret event dynamics.
